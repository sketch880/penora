# Penora — پلتفرم نگارش مقاله و پایان‌نامه

سایت کامل فارسی برای خدمات نوشتن مقاله علمی، پایان‌نامه و ویرایش، با قابلیت ثبت‌نام، چت، آپلود فایل، پنل مدیریت و **پنل پشتیبانی**.

## ویژگی‌ها

- ✅ ظاهر حرفه‌ای و آرامش‌بخش
- ✅ ثبت‌نام و ورود با نام کاربری یکتا
- ✅ داشبورد کاربر + ثبت درخواست
- ✅ چت آنلاین با آپلود فایل
- ✅ کنترل حجم و فرمت فایل از پنل ادمین
- ✅ پنل مدیریت (کاربران، نقش‌ها، درخواست‌ها، تنظیمات)
- ✅ **پنل پشتیبانی مجزا** — ادمین نقش «پشتیبان» می‌دهد و آن شخص با همان ایمیل/رمز وارد می‌شود
- ✅ آماده دیپلوی روی Vercel + Supabase

## راه‌اندازی گام به گام

### ۱. ساخت پروژه Supabase

1. برو به [supabase.com](https://supabase.com) و پروژه جدید بساز.
2. از **SQL Editor** محتوای فایل `supabase-schema.sql` را کامل اجرا کن.
3. از **Storage** یک bucket به نام `uploads` بساز.
4. از **Project Settings → API** مقادیر `Project URL` و `anon public` key را کپی کن.

### ۲. تنظیم پروژه

```bash
cd penora-app
npm install
```

فایل `.env.local` بساز:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

### ۳. اجرا

```bash
npm run dev
```

### ۴. ساخت اولین ادمین (از پیش تعیین‌شده)

**روش پیشنهادی:**

1. یک کاربر معمولی با ایمیل و رمز دلخواه خودت ثبت‌نام کن (مثلاً `admin@penora.ir`).
2. در Supabase → **Table Editor** → جدول `profiles`، ستون `role` آن کاربر را به `admin` تغییر بده.
3. خارج شو و دوباره با همان ایمیل و رمز وارد شو → مستقیم به `/admin` هدایت می‌شوی.

از این به بعد همان ایمیل و رمز، پنل مدیریت کامل است.

### ۵. تعریف حساب پشتیبانی

1. شخص پشتیبان باید یک بار در سایت **ثبت‌نام** کند (با ایمیل و رمز خودش).
2. ادمین وارد `/admin` شود → تب **کاربران و نقش‌ها**.
3. نقش آن کاربر را به **پشتیبان** تغییر دهد.
4. حالا آن شخص با همان ایمیل و رمز وارد شود → مستقیم به پنل پشتیبانی (`/support`) می‌رود و همه درخواست‌ها را می‌بیند، وضعیت را عوض می‌کند و چت می‌کند.

> نکته: ساخت کاربر جدید با ایمیل/رمز فقط از طریق ثبت‌نام معمولی ممکن است (چون از سمت کلاینت به Service Role دسترسی نداریم). ادمین فقط نقش را تغییر می‌دهد.

### ۶. اگر درخواست‌ها در پنل ادمین دیده نمی‌شوند

1. مطمئن شو نقش خودت در جدول `profiles` واقعاً `admin` است.
2. دوباره فایل `supabase-schema.sql` را در SQL Editor اجرا کن (سیاست‌های RLS را به‌روز می‌کند).
3. در مرورگر کنسول را باز کن و خطا را ببین.
4. صفحه را رفرش کن.

### ۷. دیپلوی روی Vercel

1. کد را روی GitHub بگذار.
2. در Vercel پروژه را Import کن و متغیرهای محیطی را اضافه کن.
3. Deploy.

## نقش‌ها

| نقش       | دسترسی                                      |
|-----------|---------------------------------------------|
| user      | داشبورد شخصی، ثبت درخواست، چت روی درخواست‌های خودش |
| support   | پنل پشتیبانی، مشاهده و مدیریت همه درخواست‌ها، چت |
| writer    | مشابه support (برای سازگاری با قبل)         |
| admin     | همه چیز + تنظیمات فایل + تغییر نقش کاربران  |
